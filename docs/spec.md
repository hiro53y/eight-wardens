# Eight Wardens 3.2 現行追加仕様

- 5章各3通常拠点＋1ボス拠点、計20種。1〜6面は通常3種を繰り返し、7面は章固有の大型拠点。番号札・現在地旗・攻略済み旗/星・未開放の錠前で状態を示す。
- 防衛地点はfield.tsの12座標。配置番号0〜11を保持し、当たり判定・射程・発射位置・連携線で同じデータを使う。350px以内の辺を短い順に相互接続し、各地点最大3本。連携倍率は維持する。
- 新規開始の8人を分散配置。旧セーブは番号を変更せず同番号の新地点へ対応する。保存形式v3とキーは維持する。
- 8人×待機/構え/攻撃の3ポーズ。左向きを基本とし、対象の左右差28px以内は向きを維持、それ以外は対象へ向く。足元のアンカーでポーズを切り替え、動作後は元の位置へ戻す。
- 通常10攻撃系統をmotion.ts/strikes.tsで定義。通常0.26〜0.55秒を基準に倍速で短縮。既存の攻撃計算や命中回数を演出のために遅らせない。技は局所効果と端のカットイン、全画面の光と揺れは無効。
- Settings.effectsをstandard/reducedで追加。旧設定/不正値はstandard。標準の粒は240・局所効果は各90件、控えめは70・各30件を上限にし、終了時に除去する。演出は戦闘の乱数を使わない。
- 数値調整は許可されたが、配置変更だけで通常40戦以内/玄人60戦以内を満たしたため、射程・敵HP・能力・費用・報酬は変更しない。
- v3.1の保存検証・敵情報・技警告は継続。起動を止める保存確認やバックアップ復元画面は追加しない。

## v3.1の仕様記録

# Eight Wardens 3.1 追加仕様

既存の8人・21職・35面・育成/装備/施設/塔/毎日の挑戦はREADMEに従う。数値バランスとボスAIは3.0を維持。

- シミュレーションは1/30秒。余り時間をBattle.carryへ保持し、画面更新間隔から独立させる。停止中は時間を追加しない。
- 敵情報は実際の表示座標から判定。死亡/通過/潜行/未発見の隠密は対象外。仲間・台座の操作を優先。閲覧を閉じても元の停止状態は維持する。
- ボス予告はbossState.nextAtと候補技の読取りだけ。乱数を消費せず、確定した次技として表示しない。怒りによる即時行動の可能性を説明する。
- 必殺技の対象問合せと効果適用を共有。対象なし警告は操作禁止ではない。金貨補助技は攻撃対象の警告を出さない。
- 保存キー/形式v3/PWA識別は維持。旧v2は検証後に移行、省略可能な一時状態のみ補完する。読めない原文を読み込み時に上書きしない。保存不可でも画面は動作する。新規開始時の従来の上書き確認は残す。
- 追加画像10点と元の不透明人物シートからの復元1点をv31配下へ配置。既存素材を上書きしない。役割の見分けと全身・武器の収まりを優先。
