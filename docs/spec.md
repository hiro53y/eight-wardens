# Eight Wardens 3.1 追加仕様

既存の8人・21職・35面・育成/装備/施設/塔/毎日の挑戦はREADMEに従う。数値バランスとボスAIは3.0を維持。

- シミュレーションは1/30秒。余り時間をBattle.carryへ保持し、画面更新間隔から独立させる。停止中は時間を追加しない。
- 敵情報は実際の表示座標から判定。死亡/通過/潜行/未発見の隠密は対象外。仲間・台座の操作を優先。閲覧を閉じても元の停止状態は維持する。
- ボス予告はbossState.nextAtと候補技の読取りだけ。乱数を消費せず、確定した次技として表示しない。怒りによる即時行動の可能性を説明する。
- 必殺技の対象問合せと効果適用を共有。対象なし警告は操作禁止ではない。金貨補助技は攻撃対象の警告を出さない。
- 保存キー/形式v3/PWA識別は維持。旧v2は検証後に移行、省略可能な一時状態のみ補完する。読めない原文を読み込み時に上書きしない。保存不可でも画面は動作する。新規開始時の従来の上書き確認は残す。
- 追加画像10点と元の不透明人物シートからの復元1点をv31配下へ配置。既存素材を上書きしない。役割の見分けと全身・武器の収まりを優先。
