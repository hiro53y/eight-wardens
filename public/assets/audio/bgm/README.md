# BGM mp3 placement

Place mp3 files here with these exact filenames:

- `title.mp3`: title screen
- `map.mp3`: stage select map
- `unit-management.mp3`: unit management screen
- `settings.mp3`: settings screen
- `training.mp3`: repeatable training stage battle
- `stage-1.mp3` to `stage-10.mp3`: normal stage battles

Missing files are allowed. The game stays silent for missing tracks.
